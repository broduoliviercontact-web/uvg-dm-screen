# UVG Digital DM Screen

A self-contained, interactive digital DM screen for the [Ultraviolet Grasslands](https://www.drivethrurpg.com/product/338383/Ultraviolet-Grasslands-and-the-Black-City) tabletop RPG by Luka Rejec.

Built from the original tables by **Saker Tarsos** of the StratometaShip.

## Live Demo

https://dewy-marvel-wef8.here.now/

## What's Inside

| Module | Function |
|--------|----------|
| **DM Tools** | Hero generator, skills, NPC voyager, GM power, death oracle |
| **Biomagic Corruption** | Exposure levels, beneficial/cosmetic/deleterious mutations |
| **Travel** | Quests, carousing, misfortune, encounters, chases, discoveries, directions, foraging |
| **Setting** | History & culture, locations & discoveries, climate, geography |
| **Rumors** | By faction: Cats, Humanity, Porcelain Princes, Spectrum Satraps, Nomads, Ultras, Vomes |
| **Supplies** | Essentials, toolkits, epic vehicles, hirelings, weapons |
| **Trade** | Market research, haggling, trade goods, routes, obstacles |
| **Zoa Generator** | Full lifeform generator across all kingdoms |
| **Neozoa Modificator** | 20 mutation/modification tables |
| **Research** | Expeditions, events (humorous/mundane/terrifying), faked research risks |
| **Naturalist Discoveries** | 20 result categories with nested sub-tables |

## Tech

- Pure HTML/CSS/JavaScript — no build step, no dependencies
- Self-hosted tables (all dice rolls run client-side)
- Retro VT323 terminal aesthetic matching the UVG setting
- Single-file deploy (`index.html`) — works offline after first load

## Usage

Open `site/index.html` in any modern browser. Click the buttons to roll on tables. The app is fully functional without an internet connection.
